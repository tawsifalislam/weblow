পাসকোড দিন

এই অ্যাডমিন প্যানেল শুধু আপনার জন্য। প্রথমবার পাসকোড সেট করুন — এটা শুধু আপনার ব্রাউজারে থাকবে, সাইটে কোথাও লেখা থাকবে না।

১. GitHub টোকেন

Publish করতে একবার টোকেন বসাতে হবে। টোকেন শুধু আপনার ব্রাউজারে থাকে — আমাকে বা আর কাউকে পাঠাতে হবে না।

  1. এখানে ক্লিক করে টোকেন বানান
  2. Token name: weblow-admin
  3. Repository access: Only select repositories → tawsifalislam/weblow
  4. Repository permissions → Contents: Read and write
  5. Generate token → কপি করে নিচে বসান
টোকেন বসানো হয়নি।

নিরাপত্তা

পাসকোড শুধু আপনার ব্রাউজারে থাকে। অন্য কেউ আপনার ফোন/ব্রাউজার না পেলে ঢুকতে পারবে না। পাসকোড ভুলে গেলে ব্রাউজারের সাইট ডেটা মুছে আবার সেট করুন।
